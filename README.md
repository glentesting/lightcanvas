# LightCanvas

AI-assisted Christmas light show designer. Upload a song, sync effects to the beat, preview your house lighting up, export to xLights or Light-O-Rama.

## Quick Start

```bash
npm install
cp .env.local.example .env.local  # Fill in Clerk + Supabase keys
npm run dev
```

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Clerk · Supabase · Zustand · WaveSurfer.js · Vercel
