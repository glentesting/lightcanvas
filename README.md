# LightCanvas

AI-assisted Christmas light show designer. Upload a song, sync effects to the beat, preview your house lighting up, export a `.loredit` file for Light-O-Rama S6.

## Quick Start

```bash
npm install
cp .env.local.example .env.local  # Fill in Supabase + Anthropic keys
npm run dev
```

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Supabase · Zustand · WaveSurfer.js
